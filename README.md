# Proyecto de Machine Learning

# Requisitos
- Python 3.14.4
- Git
- uv

# Instalación
### 1. Instalar uv
```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
source ~/.bashrc
```

### 2. Crear y sincronizar el entorno
```bash
uv sync
```

### 3. Activar el entorno
```bash
source .venv/bin/activate
```
